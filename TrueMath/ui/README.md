# TrueMath UI

This folder contains the React/Vite frontend that is embedded into the desktop
application build.

## Commands

```powershell
npm ci
npm run lint
npm run build
```

## Versioning

- `ui/package.json` version is synchronized from the repository `VERSION` file
- `ui/src/version.js` is generated by `scripts/sync-version.ps1`

## Release Notes

- Output is published to `ui/dist`
- The packaged desktop app serves `ui/dist/index.html`
- Do not commit ad hoc version strings directly in React components
