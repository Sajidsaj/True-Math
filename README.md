# TrueMath Innovator - Official Support & Documentation

Welcome to the official support and documentation page for **TrueMath Innovator**, an advanced Autonomous Mathematical Research and Verification Engine available on the Microsoft Store.

## 🚀 Product Overview
TrueMath Innovator is a specialized environment designed for mathematicians, researchers, and students to explore complex mathematical structures, verify mathematical conjectures, and compute exact symbolic mathematics with 100% accuracy.

### Key Features:
* **Exact Math Solver:** Computes exact derivatives, integrals, equations, and factorizations powered by localized Python execution (via SymPy) to eliminate AI hallucinations.
* **Unsolved Problems Exploration:** Numerically tests patterns around famous unsolved problems, including the **Riemann Hypothesis** and real-time arXiv.org research data integration.
* **Conjecture Checker:** A high-performance brute-force computation engine to test limits on famous math theories like the **Collatz Conjecture**.
* **Hard Problem Solver:** Executes proven mathematical algorithms (such as Dijkstra, LP, Miller-Rabin, and Pollard's rho) alongside custom ring/group/field universe verifications.
* **Live Math Discoveries:** Generates and verifies novel mathematical identities instantly.
* **MCTS Decision Tree & Verification:** Visualizes mathematical search branches utilizing Monte Carlo Tree Search (MCTS) and counts live **Lean 4 Truth Ratio** tokens.

## 🛠️ App Capabilities Notice (For Microsoft Certification)
To deliver heavy mathematical crunching and bulletproof logic verification without slowing down the UI, TrueMath Innovator splits its architecture into independent local subprocesses:
1. **`localSystemServices` / `packagedServices`**: These restricted capabilities are strictly used to spin up, manage, and communicate with the isolated **Lean 4 theorem prover** and localized Python computation kernels on the user's machine.
2. **Inter-Process Communication (IPC)**: The frontend user interface connects to these backend mathematical engines via local secure IPC. No user data or source code ever leaves the secure local sandbox environment.
